# Code of Conduct

Contributors are expected to be respectful, constructive, and technically
honest. Discussion should focus on the code, numerical evidence, documentation,
and the needs of people using Pepsy.

Harassment, discrimination, personal attacks, and knowingly misleading
technical claims are not acceptable. Maintainers may remove contributions or
restrict participation when behavior violates these expectations.

Report concerns privately to the repository maintainers rather than escalating
them in a public technical thread.
