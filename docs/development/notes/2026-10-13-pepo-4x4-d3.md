# Full-PEPO 4×4, D=3 boundary-cap validation

**Fixed caps `(81,324)` matched dense fidelity and normalization on this
fixture; valid low-cap diagnostics alone did not certify accuracy.**

These were roundoff-reference budgets, not a measured minimum for practical
evolution. The previous random-state result does not establish that every
`D=3` PEPS requires these caps.

## Where 81 and 324 came from

A fully fused four-site boundary has at most $q^2$ Schmidt rank at its middle
cut (two sites per side). Its per-site open-index dimension is $q=D^2$ for a
bra/ket norm and $q=D_{\mathrm{bra}}D_{\mathrm{PEPO}}D_{\mathrm{ket}}$ for
the bra/PEPO/ket overlap. Thus the conservative reference budgets were

$$
{\color{blue}\chi_{\mathrm{norm,ref}}}=(3^2)^2=81,
\qquad {\color{purple}\chi_{\mathrm{overlap,ref}}}=(3\cdot2\cdot3)^2=324.
$$

This is a four-site fused-boundary bound, not a general boundary-cap rule for
larger lattices or a minimum for an approximately contracted state. The
native sequential-layer implementation was checked against the dense oracle
separately. For a single-layer amplitude on this same geometry the analogous
reference is $D^2=9$, rather than either multi-layer budget. Four configurations
of the random `D=3` state gave relative amplitude errors `0.330`, `0.0757`,
`1.9e-15`, `1.9e-15` at single-layer caps `3,6,9,12`, respectively.

## Small-step product-state follow-up

Fresh runs started from $|+\rangle^{\otimes16}$ with `dt=0.01`, `J=h=1`,
three steps to `t=0.03`, zero cutoffs, and fixed caps `(18,72)` or `(36,144)`.
Both produced the same tensors' dense vector, grew from output `D=2` on the
first step to `D=3` on the second, and retained `D=3` on the third.
Final exact circuit infidelity was `4.6163e-11`; squared norm was
`0.9999999999999981`. Reported final-step infidelity differed from dense by
less than `1e-14`. See [full evidence](2026-10-13-pepo-small-step-caps.json).

Thus `(18,72)` sufficed for this early, weakly entangled startup. The caps were
fixed and no growth was needed. This does not establish adequacy at `t=0.4`
or for the paper's critical-field quench (`h=3.04438`), which was not run.
The second/third fits retained an already accurate operator-compressed warm
start because the attempted sweep did not improve it; this is not evidence
of extensive ALS convergence on a strongly entangled state.

## Reference and budgets

Complex128 random PEPS, seed `20261013`, normalized against its 65,536-entry
dense vector. Apply a full bond-2 TFIM Strang PEPO with `dt=0.1`, `J=h=1`,
open boundaries, and fixed output `D=3`. All fit/metric/warm cutoffs are zero.
Each fit uses one backward/forward round trip per axis, with the existing
inner ALS and boundary FIT budgets. NumPy CPU uses one BLAS/OpenMP thread.
Some probes overlapped; timings are observational rather than a speed ranking.

The oracle applies onsite rotations and ZZ phases directly to the vector;
it does not contract the PEPO or reuse boundary environments. Every fit is
evaluated against its own full, uncompressed target. Circuit fidelity is a
separate accumulated comparison in the [JSON evidence](2026-10-13-pepo-4x4-d3.json).

$$
{\color{blue}F}=\frac{|\langle\psi_D|U\psi\rangle|^2}
{\|\psi_D\|^2\|\psi\|^2},\qquad
{\color{purple}\mathcal L}=1-F.
$$

All outputs retained `D=3`. Step-one warm infidelity was `0.212805685` for
every run; all fits improved it. Sufficient-cap reported losses agree with
dense losses within `7e-15`; exact squared norms agree within `3e-16`.
Most time belongs to the complete sweep phase (about 103/109 seconds at the
larger caps); its boundary/local-solve split was not retained in these logs.

Failure recovery doubled caps through `(2,4)`, `(4,8)`, `(8,16)`, `(16,32)`.
Failures were invalid whole-state fidelity and invalid local normalized
overlap. The final valid estimate still understated dense loss by `0.00766`.
This policy detects numerical failure; it does not measure cap convergence
on healthy steps, consistent with the user's request to avoid routine probes.

## Independent metric convergence

After each fit, the probe holds its tensors fixed and contracts only the
norm/overlap at larger caps. These diagnostics run in the explicit benchmark,
not automatically in production evolution. For the low-cap output:

| Metric caps | Step-one absolute loss error | Step-two absolute loss error |
| --- | ---: | ---: |
| `(36,144)` | `1.1162e-3` | `1.3121e-3` |
| `(72,288)` | `4.0123e-6` | `1.9041e-6` |
| `(144,576)` | `0` | `1.0214e-14` |

For the fixed `(81,324)` output, evaluating at those same caps agrees with
dense fidelity within `7e-15` at both steps. Evaluating at `(72,288)` still
differs by `6.53e-6` and `1.74e-6`. Thus `(81,324)` is sufficient for this
fixture; increasing caps further is unnecessary for its metric accuracy.
The residual fit loss near `0.1` also reflects output representation and
optimization; an exact contraction is not an exact compression certificate.

## Reproduction

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
python examples/tfim_pepo_chi_probe.py --steps 2 --norm-chi 81 \
    --overlap-chi 324 --fixed --probe-chis 36 72 81
```

The example flushes JSON records for setup, each fit and each cap diagnostic.
Failure growth is also printed immediately on stderr. This bounded live
probe creates no persistent background jobs or checkpoints. The retained
[regression](../../../tests/test_peps_pepo_4x4.py) uses one axis to reduce
runtime and checks dense improvement, metric/norm accuracy, fixed ranks and
unchanged source/operator arrays.

## Bond balancing

Installed Quimb `balance_bonds_()` preserved a dense 2×2 `D=3` state to
relative amplitude error `3.3e-16`. Both sparse and flat Symmray Z2 raised
`NotImplementedError` for `einsum('abc,abc->a')`; that repeated-index
contraction is unsupported by the installed Symmray implementation.
Do not densify a native state merely to call this gauge helper. Dense
balancing may help scales between accepted steps; rebuild affected boundary
caches afterward. It does not make low-cap fidelity reliable and can change
finite-cap estimates even while preserving the exact state.
